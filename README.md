# Fuga Releases

The official download repository for Fuga plugins. It holds the published versions of all Fuga plugins, up to the newest release.

## What's included

- **CCX** plugin packages
- **UXP** plugins
- **CEP** extensions
- **Core** plugin installers

## Where to find each plugin

| Plugin | Folder | File |
|--------|--------|------|
| CoDesigner panel for InDesign (Mac and Windows) | `UXP` | `CoDesigner-v<version>.ccx` |
| Core plugins for InDesign, Mac | `Native/v<version>` | `FugaPlugins-v<version>-ID<InDesign year>-mac.dmg` |
| Core plugins for InDesign, Windows | `Native/v<version>` | `FugaPlugins-v<version>-ID<InDesign year>-win.exe` |

## Which version to download

Use the newest version of each plugin unless Fuga has asked you to install a specific one.

This repository is for downloads only and does not contain source code.
